# Italian Recipe Cards
Three Italian recipe cards with images, descriptions, preparation times, servings and recipe links.

## How to use

Open index.html in a browser or with Live Server.
Keep styles.css in the same folder.
Replace the images, text and recipe links with your own content.

## Design decisions

- Warm beige background and plum colors create a romantic Italian feel.
- Serif headings contrast with a simple sans-serif body font.
- CSS Grid adapts the layout to different screen sizes.
- Images use object-fit: cover to avoid distortion.
- Cards and links have hover effects.
- Links have visible keyboard focus styles.
- Reduced motion preferences are respected.

## Known limitations
- Images are hosted externally and require an internet connection.
- Recipe links currently use placeholder anchors and need valid destinations.

## Known limitations

- Avatar is text-only — no image upload support
- Not fully responsive below 280px
- No hover or interactive states
- Buttons are for demonstration only and have no click functionality
